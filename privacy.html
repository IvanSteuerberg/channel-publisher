Privacy Policy

Last updated: 28 October 2026

Channel Publisher is a personal tool used only by its owner on his own YouTube channels.

Data accessed

With the owner's consent through Google sign-in, the tool accesses the owner's YouTube channels to upload videos, captions and thumbnails, set their publication schedule and metadata, and read the channels' own analytics.

How the data is used and stored

The data is used only to perform those actions. OAuth tokens and any downloaded statistics are stored locally on the owner's own computer. Nothing is sold, shared with third parties, or used for advertising, and no data from other users is collected.

Google API Services

Channel Publisher uses YouTube API Services; use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. See also the Google Privacy Policy.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.
